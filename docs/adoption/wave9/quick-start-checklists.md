# Checklist Mulai Cepat

## Semua Pengguna

- [ ] Login dengan akun sendiri.
- [ ] Pastikan nama, role, Appointment, dan periode benar.
- [ ] Baca tugas dari Beranda dan buka workflow sumbernya.
- [ ] Gunakan menu Panduan untuk langkah sesuai peran.
- [ ] Laporkan error melalui kanal bantuan resmi tanpa mengirim credential.

## Guru dan Wali Kelas

- [ ] Pastikan Teaching Assignment atau relasi Wali Kelas aktif.
- [ ] Periksa kelas, mapel, dan periode sebelum membuat materi atau asesmen.
- [ ] Review hasil AI; AI hanya membantu draft dan tidak menggantikan keputusan guru.
- [ ] Finalisasi Rapor hanya dari data dan snapshot resmi.

## Tata Usaha

- [ ] Verifikasi tahun ajaran dan semester aktif.
- [ ] Gunakan pencarian sebelum membuat data baru.
- [ ] Pastikan pencatatan keuangan dan penerima notifikasi sesuai scope.
- [ ] Jangan mengubah periode aktif melalui jalur generik.

## Siswa

- [ ] Periksa kelas, tugas, dan tenggat.
- [ ] Pastikan koneksi stabil sebelum submit asesmen.
- [ ] Baca Rapor dari periode yang sudah didistribusikan.

## Orang Tua

- [ ] Pilih anak yang benar sebelum membuka Rapor, keuangan, atau remedial.
- [ ] Pastikan nama anak tetap sama setelah membuka notifikasi.
- [ ] Gunakan kanal sekolah untuk koreksi data.
