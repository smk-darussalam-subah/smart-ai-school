# Checklist Kesiapan Data Nyata

## Governance

- [ ] Owner data, operator, reviewer, dan approver telah ditetapkan.
- [ ] Consent dan privacy notice sesuai proses sekolah.
- [ ] Appointment aktif dan stable identity telah direkonsiliasi.
- [ ] Automation aktivasi Appointment production aktif dan terpantau.

## Data

- [ ] Tahun ajaran dan semester aktif tunggal.
- [ ] Kelas, mapel, jurusan, Teaching Assignment, dan Wali Kelas lengkap.
- [ ] KKTP memiliki provenance yang disetujui.
- [ ] Data ambigu tidak ditebak atau dinormalisasi otomatis.

## Runtime

- [ ] Backup dan restore rehearsal lulus.
- [ ] Migration status clean dan health API/database/web hijau.
- [ ] Redis, notification recovery, provider AI, dan quota monitoring siap.
- [ ] Web Push, email, atau WhatsApp hanya memakai channel yang disetujui.

## Pengguna

- [ ] Quick start dibagikan sesuai peran.
- [ ] Fasilitator internal lulus latihan.
- [ ] Kanal bantuan resmi dapat diakses.
- [ ] Browser desktop/mobile minimum telah diuji.

## Keputusan

- [ ] Tidak ada P0/P1/P2 terbuka.
- [ ] Reviewer independen menyetujui gate.
- [ ] Director menyetujui batas pilot dan rollback.
